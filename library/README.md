# Library

Ready-to-boot bundles of free games from the [Ultimate Catalog of Web Game Ports](https://github.com/Carter54git/Ultimate-Catalog-Of-Web-Game-Ports), built from source by [ports/build.py](../ports/build.py). Open one in QuantiLoader, or import them all into QuantiSorter. Every bundle runs offline and carries its licence and source link in its `manifest.json`.
